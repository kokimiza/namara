fn max_of(nums: &[i32]) -> Option<i32> {
    // write this
}

max_ofを実装してください。numsの中の最大値を返し、空であればNoneを返します。

参考実装 
fn max_of(nums: &[i32]) -> Option<i32> {
    nums.iter().copied().max()
}

Iterator::max()は空のイテレータに対してすでにNoneを返すため、空かどうかを別途チェックするコードを書く必要はありません。
