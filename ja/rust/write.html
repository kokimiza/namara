fn first_word(s: &str) -> &str {
    // write this
}

first_wordを実装してください。sの中で空白より前にある最初の単語を返し、空白がなければ文字列全体を返します。

参考実装 
fn first_word(s: &str) -> &str {
    s.split_whitespace().next().unwrap_or("")
}

返されるスライスはsを借用しているため、明示的なライフタイムは不要です — 入力の参照が1つしかないため、省略された出力のライフタイムはそれと一致するものとして推論されます。
