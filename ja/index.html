Namara

毎日コード。手助けなし。

Namaraは、すでにコードが書けるプログラマが、今もその力を保てているか確かめるための、一日一問のコーディングドリルです。

AIコーディングアシスタントは便利であり、Namaraはそれに異を唱えるつもりはありません。ただ、タイピングの多くをAIが肩代わりするほど、根底のスキルがまだ自分に残っているかを確かめる機会は減っていきます。Namaraは、アシストなしで短時間だけそれを確認する場所です。

コンパイラなし、ログインなし、採点なし。以下から言語と課題の種類を選び、短いコードを読んで、自分の力だけで答えにたどり着けるか試してみましょう。3秒で終わってもかまいません。間違えてもかまいません。大事なのは何かを証明することではなく、今日一度コードに触れることです。

ドリルを選ぶ

C — READ · WRITE · DEBUG

C++ — READ · WRITE · DEBUG

Rust — READ · WRITE · DEBUG

Haskell — READ · WRITE · DEBUG

READは、コードが何をするかを予測する課題です。WRITEは、小さな関数を自分の手で書く課題です。FIXは、バグを見つけて直す課題です。いずれも採点されず、時間も計られず、他の誰かと比較されることもありません。
