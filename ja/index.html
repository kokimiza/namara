Namara

毎日書く。AIに頼らず。

Namaraは、すでにコードが書けるプログラマが、今もその力を保てているか確かめるための、毎日のコーディングドリルです。

AIコーディングアシスタントは便利であり、Namaraはそれに異を唱えるつもりはありません。そもそもAIが速さと正確さを身につけられたのは、プログラマたちが長い時間をかけて自分の手でコードを書き、技巧と知識を積み重ねてきたからにほかなりません。恥ずかしながら筆者自身、AI以前は技術ブログやスタックオーバーフローを頼りにするコピペエンジニアでした。それでも、手だけは動かしていたのです。AIがタイピングの多くを肩代わりするようになった今、その手すら動かす機会が失われつつあります。Namaraは、アシストなしで短時間だけ、根底のスキルがまだ自分に残っているかを確かめる場所です。

コンパイラなし、ログインなし、採点なし。以下から言語と課題の種類を選び、短いコードを読んで、自分の力だけで答えにたどり着けるか試してみましょう。大事なのは何かを証明することではなく、今日一度コードに触れることです。

ドリルを選ぶ

C — READ · WRITE · DEBUG

C++ — READ · WRITE · DEBUG

Rust — READ · WRITE · DEBUG

Haskell — READ · WRITE · DEBUG

READは、コードが何をするかを予測する課題です。WRITEは、小さな関数を自分の手で書く課題です。FIXは、バグを見つけて直す課題です。いずれも採点されず、時間も計られず、他の誰かと比較されることもありません。
