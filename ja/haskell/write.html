MyLength.hs

myLength :: [a] -> Int
myLength = undefined  -- write this

組み込みのlengthを使わずにmyLengthを実装してください。

参考実装 
myLength :: [a] -> Int
myLength []     = 0
myLength (_:xs) = 1 + myLength xs

ケースごとに1つの等式を書きます。空リストの長さは0、空でないリストの長さはその先頭を除いた残り(tail)の長さに1を足したものです。
