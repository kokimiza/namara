count_charを実装してください。NUL終端文字列sの中にcが何回現れるかを返します。

参考実装 
size_t count_char(const char *s, char c) {
    size_t n = 0;
    for (; *s; s++) {
        if (*s == c) n++;
    }
    return n;
}

文字列を1回だけ走査し、ループが次に進む前に各バイトを比較します。
