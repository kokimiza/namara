sum_range.c

int sum_range(int lo, int hi) {
    // write this: return the sum of every integer from lo through hi,
    // inclusive (the caller guarantees lo <= hi)
}

loからhiまで(両端を含む)の整数の総和を返すsum_rangeを実装してください。ループの境界を1つずらすだけで、両端のどちらかが抜け落ちることに注意してください。

Reference 
int sum_range(int lo, int hi) {
    int total = 0;
    for (int i = lo; i <= hi; i++) {
        total += i;
    }
    return total;
}

「両端を含む」を素直に書くなら、終了条件はi < hiではなくi <= hiです。hi自身をループの内側で足すか外側で別途足すかは実装者の自由なので、これは参考実装であり、唯一の正解ではありません。
